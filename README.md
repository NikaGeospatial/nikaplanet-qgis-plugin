# NikaPlanet QGIS Plugin

A QGIS plugin that connects you to [NikaPlanet](https://planet.nika.eco), bringing cloud-based geospatial processing directly into your desktop GIS workflow.

## What it does

- **Sign in** to your NikaPlanet account from within QGIS
- **Browse workers** shared across your team and any teams you've been invited to
- **Run jobs** by selecting a worker, configuring its inputs, and submitting it to the cloud
- **Track progress** with live status updates while your job runs
- **Download results** back into QGIS when processing is complete

## Requirements

- QGIS 3.0 or later

## Installation

- The plugin is **standalone** and does not have any dependencies
